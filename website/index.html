    Run it locally.

    The complete library, examples, notebooks, and tests live in one small repository. Install the optional VI and notebook tools, then run the first examples.

    Open the library on GitHub ↗
    Terminal · Python + uv
    git clone https://github.com/nipunbatra/smallprob.git
cd smallprob
uv sync --extra vi --extra notebook --locked
uv run --no-sync python -m examples.demo

    Requires uv. For NumPy-only exact inference, use uv sync. Torch execution is optional; exact HMM inference runs on the CPU with NumPy.
